# 洛克王国s2幸运惊喜盒监控

## 下载

在 [Releases](https://github.com/cheng1608/loco_box/releases) 页面下载 `loco_box.exe`。

## 首次启动

1. 双击运行 `loco_box.exe`，主界面如下

   ![主界面](docs/images/主界面.png)

2. 点击**监控区域**，框选包含「幸运惊喜盒」五个白字的区域

   ![监控区域](docs/images/监控区域.png)

3. 点击**截图区域**，框选盒子打完以后要截图的区域

   ![截图区域](docs/images/截图区域.png)

4. 按你的电脑配置调整参数，如果不确定可以打完盒子退出重新打慢慢调
   - **延迟**：文字消失后等待多久再截图（默认 1 秒）
   - **阈值**：匹配灵敏度（默认 0.45）
   - **亮度**：白色笔画提取阈值（默认 200）

5. 点击**开始**启动监控，按钮变为**停止**后可随时结束

6. 文字消失并确认后，程序会自动截图并显示在下方预览区

工具栏按钮（同一行）：

- **监控区域** / **截图区域**：框选对应区域
- **预览**：查看监控区域的笔画提取效果
- **测试**：在当前监控区域测试匹配分数
- **开始** / **停止**：启动或停止监控

底部状态栏会单行显示当前进度。

配置会自动保存到exe文件同目录下的 `data\` 文件夹，下次启动可恢复区域和参数，如果你不想本地多出这个文件夹，可以提个issue让我删掉，因为我也不知道配置保存在哪好

## 从源码运行

```bash
pip install -r requirements.txt
python main.py
```
